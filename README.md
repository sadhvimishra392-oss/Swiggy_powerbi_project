# 🍔 Swiggy Sales Analysis Dashboard

A Power BI dashboard project designed to analyze food delivery sales performance, customer behavior, and business trends using Swiggy order data. The dashboard provides actionable insights to support data-driven decision-making and improve business performance.

---

## 📌 Project Overview

This project focuses on analyzing Swiggy sales data to understand customer ordering patterns, revenue trends, and product performance.

The dashboard helps answer important business questions such as:

- Which cities generate the highest revenue?
- What are the top-selling food categories?
- How do sales vary over time?
- Which restaurants contribute the most orders?
- What customer trends can be observed?

---

## 🎯 Objectives

- Analyze overall sales performance
- Identify top-performing restaurants and categories
- Monitor customer ordering behavior
- Track revenue and order trends
- Support business decision-making through visual insights
